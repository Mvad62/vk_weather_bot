# VK бот погоды

VK-бот получает текущую погоду, прогноз на пять дней и качество воздуха через
OpenWeather. Выберите город в меню один раз — он будет сохранён для вашего
профиля и автоматически использоваться для следующих запросов. Другие
пользователи могут сохранить собственные города.

## Требования

- Python 3.10 или новее
- Токен сообщества VK с включёнными сообщениями
- API-ключ OpenWeather

В настройках сообщества VK включите **Сообщения сообщества**. В разделе
**Работа с API → Long Poll API** включите Long Poll и событие **Входящее
сообщение** (`message_new`). Пока пользователь сам не отправит сообщение
сообществу, VK не показывает ему клавиатуру бота. Отправьте боту «Начать» или
любое сообщение — он ответит и покажет меню.

## Установка и запуск в Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` укажите реальные значения `VK_TOKEN` и `OPENWEATHER_API_KEY`, затем
запустите:

```powershell
python bot.py
```

Либо запустите `start_bot.bat`.

## Команды меню

- **Погода сегодня** — температура, ощущаемая температура, влажность и ветер.
- **Прогноз на 5 дней** — температура и описание погоды с интервалом в 3 часа
  на следующие пять суток через стандартный бесплатный 5 Day / 3 Hour Forecast
  API OpenWeather.
- **Качество воздуха** — индекс OpenWeather от 1 до 5 и концентрации PM2.5,
  PM10, CO и NO₂.
- **Выбрать город** — задать или изменить город для последующих запросов.
  Можно ввести название вручную или отправить геопозицию из меню вложений VK:
  бот запросит текущую погоду непосредственно по широте и долготе, определит
  название места обратным геокодингом OpenWeather и сохранит его.

Сохранённые города хранятся локально в `data/user_cities.sqlite3`.

Прогноз использует стандартный endpoint `api.openweathermap.org/data/2.5/forecast`
и не требует подписки One Call API 3.0. Он возвращает прогнозные точки
трёхчасового шага (до 40 записей на пять суток), а не почасовые данные.
См. [описание 5 Day / 3 Hour Forecast](https://openweathermap.org/forecast5)
и [тарифы OpenWeather](https://openweathermap.org/price).

Не добавляйте `.env` в систему контроля версий: он исключён через `.gitignore`.
